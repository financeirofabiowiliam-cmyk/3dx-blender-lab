# 3DX Hybrid Lite 2 (Windows GUI)

This path mirrors three files from the official CloudyHellboy/ANGELS-NIGHT-WORLD branch only to compile the Windows app with GitHub Actions. No separate laboratory, no independent API.

On Windows 10 x64 (Python 3.11+), extract the ZIP and double-click `iniciar_3dx_windows.cmd`. It installs Pillow/NumPy in the user's profile and opens the native GUI. You may also open `3DX-Hybrid-Lite-2.exe` once a matching Python installation with NumPy and Pillow is present: the lightweight executable uses that Python interpreter for the heavy image-analysis child.

RAM starting limit 950 MiB (optional reduced-memory 750 MiB with stop floor 520 MiB). If Render rejects requests, the GUI displays the actual error body and stops repeating permanent API errors. The official Windows helper lease protocol and 3DX asset contract remain unchanged.

The executable can only operate while Windows is powered on. Access keys are not persisted. A valid key is required for the official Render endpoint. The application does not merge local physical RAM into the Render server.
